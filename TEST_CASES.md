# Test Cases — F2F Bank

Документ содержит перечень автоматизированных E2E-сценариев проекта F2F Bank.

Для каждого сценария указаны:
- проверяемая функциональность;
- предусловия;
- входные данные;
- ожидаемый результат;
- уровень критичности;
- статус автоматизации.

## Статусы

| Статус | Описание |
|---|---|
| `Active` | Сценарий реализован и должен успешно проходить |
| `test.fixme()` | Сценарий описывает ожидаемое корректное поведение, но временно пропускается из-за подтверждённого дефекта приложения |

# 1. Авторизация

## AUTH-001 — Успешная авторизация с валидными данными

**Файл:** `tests/auth.spec.ts`  
**Приоритет:** Критический  
**Статус:** Active

**Проверяется:**  
Возможность зарегистрированного пользователя войти в систему с корректными учетными данными.

**Предусловия:**
- пользователь зарегистрирован;
- открыта страница `/login`.

**Входные данные:**
- валидный email зарегистрированного пользователя;
- корректный пароль.

**Ожидаемый результат:**
- `POST /api/auth/login` возвращает HTTP `200`;
- пользователь успешно авторизован;
- происходит переход на `/`;
- отображается форма перевода `Transfer by phone number`.
